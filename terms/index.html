第1章 総則

第1条（適用）

  1. 本規約は、当社が提供するアプリケーション「ウマゴト」および関連するサービス（以下「本サービス」といいます）の利用条件を定めるものです。利用者は、本規約に同意のうえ本サービスを利用するものとします。
  2. 当社が本サービス上で掲載するガイドライン、プラン内容の説明その他の個別規定は、本規約の一部を構成します。
  3. 本規約の定めと個別規定の定めが異なる場合、個別規定の定めが優先して適用されます。
  4. 利用者が本アプリをインストールし、または本サービスを利用した時点で、本規約に同意したものとみなします。

第2条（定義）

本規約における用語の定義は、次のとおりとします。

  1. 本アプリ: 当社が提供するアプリケーション「ウマゴト」をいいます。
  2. 本サービス: 本アプリおよび当社が運営するウェブサイトを通じて提供する一切のサービスをいい、オフライン機能およびオンライン機能を含みます。
  3. オフライン機能: 会員登録を行わずに利用できる機能をいい、データを利用者の端末内においてのみ管理するものをいいます。
  4. オンライン機能: 会員登録を行った利用者が利用できる機能をいい、当社のサーバーを通じて提供するものをいいます。
  5. 利用者: オフライン機能およびオンライン機能を問わず、本サービスを利用するすべての者をいいます。
  6. 登録ユーザー: 第6条に定める会員登録を完了した利用者をいいます。
  7. 有料プラン: 当社が定める対価の支払を条件として提供する機能の区分をいいます。
  8. 解約: 登録ユーザーが有料プランに係る契約を終了することをいいます。解約によって登録ユーザーとしての地位は終了しません。
  9. 退会: 登録ユーザーが、当社が定める手続によりアカウントの利用を終了することをいいます。
  10. 本アプリの削除: 利用者が自らの端末から本アプリを削除することをいいます。
  11. ローカルデータ: 本アプリが利用者の端末内に保存するデータをいい、第18条に定めるバックアップファイルを含みます。
  12. 会員情報: 会員登録に際して利用者が当社に提供し、当社のサーバーに保管される情報をいいます。
  13. アップロードデータ: 登録ユーザーが自らの意思により当社のサーバーに送信し、保存したデータをいいます。
  14. メディアコンテンツ: 写真、画像、動画、音声その他これらに類するデータをいいます。
  15. 推し: 利用者が本サービスに登録した対象をいい、競走馬、引退馬、乗馬その他の馬のほか、騎手、調教師その他の馬事に関わる人物を含みます。
  16. ポスト: 本サービス上で他の利用者に共有される投稿の単位をいいます。
  17. 投稿コンテンツ: ポスト、メディアコンテンツ、文章、コメントその他利用者が本サービス上で送信、投稿または共有した一切の情報をいいます。

第3条（本規約の変更）

  1. 当社は、次のいずれかに該当する場合、本規約を変更することができます。
    1. 変更の内容が利用者の一般の利益に適合するとき
    2. 変更の内容が契約をした目的に反せず、変更の必要性、変更後の内容の相当性その他の事情に照らして合理的なものであるとき
  2. 当社は、前項の変更を行う場合、変更後の内容および効力発生日を、効力発生日の14日前までに、本サービス上への掲示その他当社が適当と判断する方法により周知します。
  3. 変更後の本規約は、前項の効力発生日から適用されます。

第4条（通知または連絡）

  1. 当社から利用者への通知または連絡は、本サービス上への掲示、本アプリ内での通知、または会員情報として登録されたメールアドレスへの送信その他当社が適当と判断する方法により行います。
  2. 当社が登録されたメールアドレスに宛てて通知を発信した場合、通常到達すべき時に到達したものとみなします。
  3. 利用者は、外部認証サービスの設定によりメールアドレスが無効となった場合その他自らの事情により通知を受領できなかったことをもって、当社に異議を述べることはできません。
  4. 利用者から当社への連絡は、当社が本サービス上に掲示する方法により行うものとします。

第2章 利用登録およびアカウント

第5条（オフライン機能の利用）

  1. 利用者は、会員登録を行うことなく、オフライン機能を利用することができます。
  2. オフライン機能において作成されたローカルデータは、利用者の端末内においてのみ管理されます。ローカルデータに関する一切の権利および責任は、利用者に帰属します。
  3. 利用者が本アプリを削除した場合、ローカルデータはすべて消失し、当社はこれを復元することができません。
  4. 当社は、ローカルデータの消失、破損その他の損害について、一切の責任を負いません。

第6条（利用登録）

  1. 利用者は、当社が指定する外部認証サービス（Apple Account またはGoogleアカウント）を用いて会員登録を申請するものとします。
  2. 当社が前項の申請を承認した時点で、利用者と当社との間に本規約に基づく利用契約が成立し、当該利用者は登録ユーザーとなります。
  3. 当社は、次のいずれかに該当すると判断した場合、会員登録の申請を承認しないことがあります。この場合、当社は理由を開示する義務を負いません。
    1. 申請内容に虚偽、誤記または記載漏れがある場合
    2. 申請者が第7条に定める年齢の条件を満たさない場合
    3. 申請者が過去に本規約に違反したことがある場合
    4. その他、当社が登録を相当でないと判断した場合

第7条（年齢に関する条件）

  1. 会員登録は、18歳以上の者に限り行うことができます。
  2. 利用者は、会員登録に際して自らの生年月日を正確に申告するものとします。
  3. 生年月日は、登録後に変更することができません。ただし、当社が認めた場合または法令に基づく訂正の請求があった場合は、この限りではありません。
  4. 当社は、必要と判断した場合、登録ユーザーに対して年齢または本人であることを確認するための資料の提出を求めることができます。
  5. 登録ユーザーが年齢の条件を満たしていないことが判明した場合、当社は、当該登録ユーザーの本サービスの利用を停止し、または利用契約を解除することができます。
  6. 本条の規定は、オフライン機能の利用には適用されません。

第8条（アカウントの管理）

  1. 登録ユーザーは、自己の責任において自己のアカウントおよび外部認証サービスのアカウントを管理するものとします。
  2. アカウントを用いて行われた一切の行為は、当該アカウントに係る登録ユーザーによる行為とみなします。
  3. 当社は、外部認証サービスの停止、変更、廃止その他当社の責めに帰することができない事由により本サービスを利用できなくなった場合について、一切の責任を負いません。

第9条（登録情報の変更）

登録ユーザーは、会員情報に変更が生じた場合、遅滞なく当社が定める方法により変更の届出を行うものとします。ただし、第7条第3項に定める生年月日については、この限りではありません。

第10条（ログインおよびアカウントの切り替え）

  1. 登録ユーザーがログアウトした場合であっても、ローカルデータおよびローカルデータとアップロードデータとの関連づけは維持されます。
  2. 利用者が、直前まで本アプリで利用していたアカウントと異なるアカウントでログインした場合、当該端末のローカルデータはすべて削除されます。当社はこれを復元することができません。
  3. 退会した登録ユーザーが、退会前と同一の外部認証サービスのアカウントを用いて再度会員登録を行う場合、前項は適用されず、ローカルデータは削除されません。
  4. 前項の場合においても、退会前のアップロードデータおよび会員情報は復元されず、新たなアカウントとして取り扱われます。

第11条（退会）

  1. 登録ユーザーは、当社が定める手続により、いつでも退会することができます。
  2. 有料プランを契約している登録ユーザーは、退会に先立ち、第25条に定める解約の手続を完了する必要があります。App内課金により契約している場合、退会の手続を行っても課金は自動的に停止しないため、登録ユーザー自身がApple所定の方法により解約を行う必要があります。
  3. 退会した場合であっても、ローカルデータは削除されません。退会した利用者は、引き続きオフライン機能を利用することができます。
  4. 当社は、退会の手続に際して、ローカルデータの削除を行うかどうかを利用者に確認します。利用者が削除を選択した場合、ローカルデータはすべて消失し、当社はこれを復元することができません。

第12条（退会後のデータの取扱い）

  1. 退会した場合、当社は、会員情報のうち利用者個人を特定することができる情報、ならびにアップロードデータのうちメディアコンテンツおよびこれに関連する位置情報を、速やかに消去します。
  2. 前項に定めるもの以外の情報については、当社は、次の目的のために必要な期間、これを保管します。
    1. 不正な利用および再登録の検知ならびに防止
    2. 紛争、苦情その他法的請求への対応
    3. 個人を識別することができない形式に加工したうえでの統計および分析
  3. 退会した後、当該アカウントに係るポスト、コメントその他の投稿コンテンツは、他の利用者が閲覧することができない状態となります。
  4. 当社は、退会したアカウント、アップロードデータおよび投稿コンテンツの復元には一切応じません。
  5. 本条の規定は、法令に基づく開示、訂正、利用停止または消去の請求に応じる当社の義務を妨げるものではありません。

第3章 本サービスの内容

第13条（本サービスの提供内容）

  1. 本サービスは、利用者が推しに関する記録を作成し、保存し、および他の利用者と共有することを目的とするサービスです。
  2. 本サービスは、オフライン機能とオンライン機能により構成されます。オンライン機能は、会員登録を行った利用者に限り利用することができます。
  3. 当社は、本サービスの内容、機能および仕様を、利用者への事前の通知なく変更することがあります。ただし、利用者に重大な影響を及ぼす変更を行う場合は、第19条に定める手続によります。

第14条（プランおよび提供機能）

  1. 当社は、本サービスにおいて複数のプランを提供します。各プランの内容、対価および利用可能な機能は、当社が本サービス上に掲示するところによります。
  2. 当社は、プランの構成、内容および対価を変更することがあります。この場合、第27条の定めによります。

第15条（賭事に関する取扱い）

  1. 本サービスは、馬、レースおよび馬事に関わる人物に着目し、これらに関する記録および共有を通じて馬事文化に親しむことを目的とするサービスです。
  2. 本サービスは、勝馬投票券の販売、その購入の媒介または取次ぎを行うものではありません。
  3. 本サービスは、勝馬投票券の的中を目的とする予想情報の提供を目的とするものではありません。
  4. 利用者は、本サービスを賭事の勧誘、賭事に関する情報の販売その他これらに類する目的で利用してはなりません。馬券および予想に関する禁止行為の詳細は、第38条の定めによります。

第16条（動作環境）

  1. 本アプリは、当社が本サービス上に掲示する動作環境において利用することができます。
  2. 本サービスの利用に必要な端末、通信機器、通信回線その他の環境は、利用者が自己の費用と責任において用意するものとします。
  3. 当社は、すべての端末および環境における本サービスの動作を保証するものではありません。

第17条（データの保存および容量）

  1. 当社は、プランごとに、アップロードデータの容量、メディアコンテンツの解像度その他の品質および数の上限を定めます。上限の内容は、当社が本サービス上に掲示するところによります。
  2. 登録ユーザーのアップロードデータが上限を超過している場合、当該登録ユーザーは、新たなポストの共有その他当社が定める機能を利用することができません。
  3. 前項の状態は、登録ユーザーが自らアップロードデータを削除し、上限の範囲内となった時点で解消されます。
  4. 有料プランを解約した場合の取扱いは、第25条の定めによります。

第18条（バックアップ）

  1. 当社は、ローカルデータを利用者の端末内のファイルとして書き出す機能を提供することがあります。
  2. 書き出されたファイルの保管、管理および利用に関する一切の権利および責任は、利用者に帰属します。当社は、当該ファイルについて一切の責任を負いません。
  3. 当社は、アップロードデータについて、当社が必要と判断する範囲でバックアップを行うことがありますが、その完全性を保証するものではありません。

第19条（本サービスの中断、変更および終了）

  1. 当社は、本サービスの全部または一部を中断、変更または終了する場合、その14日前までに、本サービス上への掲示その他当社が適当と判断する方法により、利用者に通知します。
  2. 前項にかかわらず、当社は、次のいずれかに該当する場合、事前の通知なく本サービスの全部または一部を中断することができます。
    1. 本サービスに係る設備の保守または点検を緊急に行う必要がある場合
    2. 火災、停電、天災地変その他の不可抗力により本サービスの提供が困難となった場合
    3. 通信回線、外部認証サービス、決済に関するサービスその他の第三者が提供する役務の停止または障害が生じた場合
    4. 法令の制定もしくは改正、または監督官庁の措置により本サービスの提供が困難となった場合
    5. その他、当社が緊急に中断する必要があると判断した場合
  3. 当社は、定期的な保守または点検のために本サービスを一時的に停止することがあります。この場合、第1項は適用されず、当社は本サービス上への掲示により事前に通知します。
  4. 当社が本サービスを終了する場合、当社は、終了の公表と同時に有料プランの新規の申込みの受付を停止します。この場合、当該時点において有効な有料プランのうち契約期間の満了日が最も遅い日をもって、本サービスの提供を終了します。
  5. 前項の場合、当社は、対価の返金を行いません。
  6. 当社は、本サービスの中断、変更または終了により利用者に生じた損害について、一切の責任を負いません。

第4章 料金および決済

第20条（有料プランの申込み）

  1. 登録ユーザーは、当社が定める方法により有料プランを申し込むことができます。
  2. 有料プランは、当社が定める決済の経路（App内課金またはオンライン決済）により提供されます。いずれの経路により提供するかは、プランごとに当社が本サービス上に掲示します。
  3. 有料プランに係る利用契約の相手方は、決済の経路にかかわらず当社とします。

第21条（App内課金）

  1. App内課金により有料プランを申し込む場合、購入の手続、対価の決済、契約の管理および解約は、Apple Inc. が定める条件および方法によります。
  2. 前項の場合、Apple Inc. が定める条件が本規約に優先して適用されることがあります。
  3. App内課金に係る返金の可否および手続は、Apple Inc. の判断および定めによります。当社は、返金の可否について判断する立場になく、これに関する責任を負いません。
  4. 当社は、Apple Inc. から解約その他の契約状況に関する情報を受領した時点をもって、当該事実を認識したものとします。当社の処理は、当該時点を基準として行われます。

第22条（オンライン決済）

  1. オンライン決済により有料プランを申し込む場合、登録ユーザーは、当社が指定する決済代行事業者を通じて対価を支払うものとします。
  2. 当社は、クレジットカード番号その他の決済に関する情報を保持しません。当該情報の取扱いは、決済代行事業者およびカード発行会社の定めによります。
  3. オンライン決済に係る取引条件は、特定商取引法に基づく表記に定めるところによります。

第23条（契約期間および自動更新）

  1. 有料プランの契約期間は、当社が本サービス上に掲示するところによります。
  2. 有料プランは、契約期間の満了日までに解約の手続が行われない限り、同一の内容で自動的に更新されます。
  3. 解約の手続の期限は、決済の経路ごとに異なります。App内課金の場合はApple Inc. が定める期限によります。

第24条（プランの変更）

  1. 登録ユーザーは、上位のプランへ変更することができます。下位のプランへ変更することはできません。
  2. 下位のプランの利用を希望する場合、登録ユーザーは、契約中の有料プランを解約したうえで、あらためて申し込むものとします。
  3. App内課金により契約しているプランからオンライン決済により提供されるプランへ変更する場合、登録ユーザーは、App内課金に係る解約の手続を行ったうえで、あらためて申し込むものとします。
  4. 前項の場合において、解約後も契約期間が満了していないときは、当社は、当社が定める方法により契約期間の満了日および支払済みの対価の額を確認できた場合に限り、変更後のプランの初回の請求額から、次項に定める控除額を控除します。当社がこれらを確認できない場合、控除は行いません。
  5. 前項の控除額は、解約したプランについて支払済みの対価の額を当該契約期間の日数で除し、これに残日数（変更後のプランの契約が開始した日から当該契約期間の満了日までの日数をいいます）を乗じた額とします。当該額に1円未満の端数が生じた場合、当該端数は切り上げます。
  6. 控除額が変更後のプランの初回の請求額を上回る場合、控除額は当該請求額を上限とし、当社は差額の返金を行いません。
